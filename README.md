# 不咕鸟龙与地下城线下团辅助工具 · easy-cc

面向龙与地下城五版线下跑团的资源查阅工具，提供5etools中文资料手动下载、本地缓存、解析引用、角色资源整理、收藏和骰盘。提供角色首页速览、基础数值辅助及手动记录，不代替完整电子角色卡。

底部五入口为骰子、速查、角色、规则、信息；角色包含速览、起源、职业、特性、法术、背包。支持深色幻想与明亮冒险两套Kenney PNG主题及Fusion Pixel字体。PWA已接入安装清单、应用离线包和显式更新；Android外部资料使用应用私有文件目录。自选存储目录尚未实现。

## 开发与部署

```sh
npm ci
npm run dev -- --host 127.0.0.1 --port 5195 --strictPort
```

本地地址为 http://127.0.0.1:5195/DND5R-easy-cc/ 。GitHub Pages工作流安装锁定依赖、构建dist并上传Pages产物。仓库不保存本机dist和node_modules。

## Android工程

使用锁定的Capacitor 8.6.0，Node.js要求22及以上；CI使用24。应用包名为`com.nogubird.easycc`，原生工程位于`android`，网页与Android共用业务源码。

```sh
npm run build:android
npm run android:sync
```

Android网页产物独立放在`dist-android`，随后同步进原生工程；上述命令不生成APK。Android使用明确的资源清单，不打包本机参考PDF、可选本地中文资料包或PWA服务，内置采用已公开的SRD发布数据。网页构建仍输出`dist`并保留PWA。

Android原文下载经原生文件与活动版本清单保存，目录继续由Worker解析；旧Android WebView原文缓存首次读取时校验迁移且原缓存保留。角色、收藏和设置仍使用WebView本地存储。返回键/生命周期、正式图标、发布签名及真机断网/升级兼容尚待验证，不能将构建成功视作设备验收通过。

配置JDK 21与Android SDK环境后，在android目录执行`./gradlew.bat --no-daemon --console=plain assembleDebug`生成调试包；输出为`android/app/build/outputs/apk/debug/app-debug.apk`。调试签名不用于正式发布。网页/Android网页构建、类型检查和9项针对性测试已通过，设备运行另行验证。

## 仓库内容

- components、contexts、hooks、src、styles、data：运行源码、适配层及发布数据。
- public：应用实际使用的字体、图标、骰盘、美术、作者支持二维码及对应许可。
- .github/workflows：部署流程；package-lock.json用于依赖复现。
- docs、本地接手记录、参考PDF、历史归档、美术原始压缩包、用户角色导出和资料制作脚本只保留本地，不随仓库更新上传。

浏览器中的角色、收藏和外部原文缓存不会随源码推送到GitHub。不同站点地址的浏览器存储彼此独立；迁移前请在信息页导出相应备份。

## 内容与素材

中文主库接入 tjliqy/5etools-cn 的cn2.0分支，Homebrew按独立资料包处理。下载由玩家主动发起；外部内容不随应用源码整库发布。各条目保留出处及解析记录。

工具作者不拥有外部规则或译文的著作权。中文源许可原文位于public/sources，字体、图标、Kenney UI、Dice-Box及骰型图的作者与许可随实际素材保留。应用信息页提供查阅入口。不能以代码或某一素材的许可代替其他外部内容的许可。

公开版内置DND5eChm/SRD5.2Chm来源的中文资料，按CC BY 4.0保留署名、许可与转换记录，见public/sources/builtin-SRD-NOTICE.txt。2014中文库及参考PDF仍保留本地；PHB补文仅公开独立出处清单。本地data/builtin不作为公开部署依赖。


## 资料管理

信息页集中管理中文主库、扩展资料包及本地原文导入导出。主库区分已保存、目录未就绪、下载未完成与检查更新结果；扩展包在独立面板中筛选、查看及批量下载。问题记录按需打开，应用安装与离线状态单独查看。关闭管理面板不取消正在进行的下载。资料下载与角色可用来源分别设置。

## 安装与离线

首次联网打开正式站点，在信息页“应用与离线”确认“应用离线包已就绪”，再通过浏览器安装或添加到主屏幕。应用包包括页面、字体、图标、解析线程和骰盘资源；外部规则仍需玩家先主动下载/导入。应用与资料使用不同存储机制，应用升级不清除角色、收藏或规则原文。

新版完整下载后提示“更新并刷新”，由玩家确认应用；更新可能刷新本工具其他标签页。开发服务器不注册Service Worker，离线功能以正式构建为准。首次安装、断网重启、iOS安装和3D骰盘仍需实际设备核对。浏览器清理站点数据会移除本机记录，请保留备份。

PWA构建由scripts/pwa-build.ts根据实际dist文件生成sw.js及内容哈希，无需手动维护缓存文件列表。Tailwind已改本地构建，不依赖运行时CDN。


## Android预装原文资料

Android构建需要本机准备的原文快照，网页构建不打入该快照：

```sh
npm run prepare:android-library -- <本地5etools中文库目录>
npm run build:android
npm run android:sync
```

制作脚本读取与主库同步相同的76文件清单，保留JSON及未知字段、附SHA-256清单。local-resources为本地原文输入，不入Git、不混入public目录；Android资源插件校验后仅发出到Android产物resources目录。首次启动没有中文主库时离线安装，同一原生写队列保证已有下载/导入优先，不自动覆盖旧资料。预装为玩家资源及解析依赖，不代表整本书或怪物百科。


发布顺序为 GitHub 网页版、基于同站点更新的 PWA，再到 Android APK。网页和 PWA共用默认构建与同一部署，不需要分别发布；Android使用独立构建及本机预装资料输入。


## 角色首页与记录

点击角色卡进入默认速览首页，通过六项页签切换配置。速览将各属性与其豁免、技能按列关联，生命骰与生命共同展示；随身装备、起始装备、财宝及钱币余额与分类库存在背包管理，装备仅从该角色已持有物品选择。库存和装备共用逐件身份，卸下不删除库存。

速览读取明确的种族/背景属性加值、职业/背景技能选项、主职业法术位矩阵和各职业生命骰；推荐数组来自本机2024手册原表。两类来源加值独立开关，可混用；待选项由玩家选择，调整值和总等级熟练加值计算后可覆盖。技能重复不叠加，不自动授予替代项；专长/装备/特性正文的额外数值手动填写。法术位不计算兼职合并，契约魔法及未支持的结构显示核对提示；总数、消耗、生命和笔记手动记录，不自动休息恢复。

属性/技能点击数值打开精简记录窗；法术位在速览使用Kenney原始圆形PNG逐个标记消耗，配置中仍可修改总数或核对旧记录。状态标记随角色备份保存，总数缩减不自动恢复已消耗法术位。

背包分为武器、护甲、工具、冒险物品、消耗品、其他魔法物品、坐骑与载具、财宝。弹药/爆炸物/食物饮品/药水/卷轴固定归消耗品；鞍具与挽具归坐骑与载具，财宝条目不自动换算钱币余额。装备专用位按类型限制；奇物部位名称只提供明确标记的建议，无建议的奇物默认额外物品，可在非专用穿戴位手动挑选。2024核心法器按已核对原文区分手持、佩戴与附着；未知形式不推断。
